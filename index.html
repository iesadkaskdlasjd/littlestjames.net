What this is

A survival server that stays small on purpose.

LittleStJames is a plain 26.2 survival world. No ranks to buy, no crates, no lobby with seventeen portals in it. You spawn, you find somewhere you like, and you start digging.

The world doesn't get reset on a schedule, so the things you build are still going to be there next month. Builds tend to cluster along the coast and spread inland from there — find a stretch of shoreline nobody has claimed and make it yours.

It's open to anyone. No whitelist, no application, no Discord you have to join first. Just be someone the rest of us want to share a world with.

The short list

Rules

  1. Don't grief, don't steal.

    Other people's builds, chests, farms and animals are theirs. If it isn't yours and you weren't invited, leave it alone.

  2. Give people room.

    Settle a good few hundred blocks from someone else's base unless they've asked you to move in next door.

  3. No cheats or X-ray.

    No hacked clients, no X-ray packs, no radar mods, nothing that plays the game for you while you're away from the keyboard.

  4. Ask before you reshape the map.

    Big terraforming near someone else's build, or draining an ocean they can see from their window, is a conversation first.

  5. Keep chat decent.

    No slurs, no harassment, no stirring things up for fun. It's a small server — it only takes one person to sour it.

  6. Clean up after yourself.

    Fill your holes, take down your dirt towers, chop the floating trees, and don't leave lava where someone is going to walk into it.

Getting in

How to join

Java Edition · Recommended

Add the server

  1. Open Minecraft: Java Edition, version 26.2.
  2. Go to Multiplayer → Add Server.
  3. Server Name: anything you like.
  4. Server Address: LittleStJames.net
  5. Save, then double-click it. That's it.

Open to everyone. Nothing to apply for, nobody to ask.

Java Edition · Fallback

Direct connect

On some networks the short address won't resolve. If it doesn't get you in, add the server again using the full address instead:

mc.LittleStJames.net:25592

Same server, same world, same people.

Heads up

Java only, for now

This is a Java Edition server. Bedrock players — console, mobile, and the Windows/Microsoft Store version of Minecraft — can't connect to it, and the address above won't work for you. Sorry. It's not a setting you can change on your end.
